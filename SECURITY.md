# Política de Segurança — LucaTur (Versão Pública Acadêmica)

## Sobre Este Repositório

Este repositório contém **exclusivamente uma versão pública sanitizada** do projeto LucaTur, criada para fins de extensão curricularizada. Ele **não representa o ambiente de produção** e não contém nenhuma informação operacional real.

---

## O Que Foi Removido

As seguintes categorias de informação foram **completamente removidas** ou **substituídas por dados fictícios** antes da publicação:

| Categoria | Status |
|---|---|
| Chaves de API (Supabase, Google, Gemini, GitHub, Mapbox) | Removidas — substituídas por `process.env.NOME_DA_VARIAVEL` |
| URLs de produção (Supabase, Netlify, GitHub Releases) | Removidas — substituídas por `https://your-project.example.com` |
| Arquivo `.env` e variáveis de ambiente reais | Não incluídos |
| Keystore Android (`.jks`) e senhas de assinatura | Não incluídos |

| Dados financeiros reais | Não incluídos |

| Configurações locais de IDE ou máquina de desenvolvimento | Não incluídas |

## Dados Fictícios Utilizados

Todos os exemplos de dados neste repositório são **completamente fictícios** e criados apenas para demonstração técnica:

- Nomes de motoristas: `João Silva`, `Maria Souza` — nomes genéricos, sem relação com pessoas reais
- Placas: `AAA-0000`, `BBB-1111` — formato de exemplo, sem relação com veículos reais
- Coordenadas GPS: valores genéricos sem relação com rotas ou cidades reais da operação
- E-mails: `exemplo@example.com` — domínio fictício
- IDs e UUIDs: gerados aleatoriamente sem relação com dados reais

## Ambiente de Produção

O sistema real de produção (LucaTur) é **privado**, operado pela empresa parceira e **não está disponível publicamente**. Este repositório não fornece acesso, não aponta para o ambiente de produção e não contém informação suficiente para reproduzir a infraestrutura real.

---

## Reportando Vulnerabilidades

Se você identificar algum problema de segurança neste repositório (por exemplo, uma credencial que inadvertidamente tenha sido incluída), por favor:

1. **Não abra uma issue pública** com informações sensíveis
2. Entre em contato diretamente com o responsável do projeto pelo e-mail disponível no perfil GitHub
3. Descreva o problema de forma clara e responsável

Agradecemos o relato responsável (responsible disclosure).

Este repositório é disponibilizado para fins **exclusivamente acadêmicos e educacionais**. Qualquer tentativa de usar as informações aqui contidas para acessar sistemas reais, reproduzir a infraestrutura de produção ou causar dano à empresa parceira é ilegal e passível de responsabilização civil e criminal.
