# Evidências Visuais — LucaTur

Esta pasta é reservada para imagens demonstrativas do projeto LucaTur, como telas, mockups ou capturas do ambiente de demonstração.

Por questões de privacidade, segurança da informação e proteção de dados operacionais, este repositório público não inclui capturas de tela do ambiente real de produção.

As evidências visuais utilizadas na entrega acadêmica devem conter apenas dados fictícios ou informações previamente anonimizadas, sem exposição de nomes reais, placas de veículos, rotas, coordenadas GPS, e-mails, valores financeiros, URLs internas ou credenciais.

Este repositório tem finalidade acadêmica e apresenta uma versão pública sanitizada do projeto.
