# Mockups e Protótipos — LucaTur

Esta pasta é reservada para mockups, wireframes ou representações visuais do projeto LucaTur.

Os materiais publicados aqui devem representar apenas o conceito da solução, utilizando dados fictícios e sem expor informações reais da empresa parceira, motoristas, veículos, rotas ou operações internas.

Caso necessário, os mockups podem ser utilizados para demonstrar o fluxo de uso do sistema, como login, painel administrativo, mapa de acompanhamento, controle de viagens e interface do motorista.

Este repositório tem finalidade acadêmica e apresenta uma versão pública sanitizada do projeto.
